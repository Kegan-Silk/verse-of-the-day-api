# Project A - Verse of the Day API
Kegan Silk

## Overview:
HTTP API service that combines two API calls for the user from one new endpoint.

### Requirements
Listed in "requirements.txt".

### Installation
##### Windows:
```
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install flask requests pytest
```
### Configuration
Set API Key

### Running the App
```
python -m flask --app app run --debug
```
